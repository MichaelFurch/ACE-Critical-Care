# ACE Critical Care

ACE Critical Care is an advanced medical gameplay expansion for Arma Reforger.

## Project Status

Milestone 0: Foundation & Preproduction

## Target Platform

Arma Reforger  
Enfusion Engine

## Base Framework

ACE Anvil Medical System

## Project Goals

- Advanced prehospital emergency medicine gameplay
- ALS/BLS gameplay support
- Trauma care systems
- Critical care systems
- Multiplayer-focused medical gameplay
- Modular architecture

## Current Milestone

### M0 – Foundation & Preproduction

M0 establishes the technical and production foundation of the project.

Current active workpackage:

`WP-M0-01 Project Infrastructure`

## Development Rules
- No medical gameplay logic is implemented during WP-M0-01.
- Project-owned files use the ACECC_ prefix.
- ACE Anvil is treated as the base medical framework.
- ACE Critical Care extends ACE Anvil modularly.
