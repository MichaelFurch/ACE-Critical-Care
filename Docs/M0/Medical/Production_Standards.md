# Asset Production Standards

## Purpose

Define production standards for ACE Critical Care assets.

## 3D Production Pipeline

| Phase | Goals | Deliverables |
|---|---|---|
| Phase 1 – Blockout | Scale validation, ergonomic validation, animation validation | Greybox models |
| Phase 2 – High Poly | Detail modeling, mechanical fidelity | High poly assets |
| Phase 3 – Game Ready Assets | Optimization, UVs, baking, texturing | Production-ready assets |
| Phase 4 – Engine Integration | Prefabs, collision, interaction points, animation hooks | Functional in-game assets |

## 3D Asset Standards

| Asset Type | Triangle Budget |
|---|---|
| Small prop | 2k–8k |
| Medium device | 10k–25k |
| Hero device | 30k–60k |

## Texturing Standards

| Type | Standard |
|---|---|
| Workflow | PBR |
| Texture Size | 2K standard |
| Hero Assets | 4K optional |
| LODs | Mandatory |

## Asset Production Strategy

High-quality medical devices are central to immersion and gameplay readability.

The project prioritizes hero assets over excessive prop quantity.

## Initial Priority Assets

- Patient monitor
- Defibrillator
- Ventilator
- Suction unit
- AED
- Airway devices

## Scope Control Rules

- Reuse existing assets where appropriate
- Prioritize gameplay-critical devices
- Focus on recognizable silhouettes
- Use staged production
